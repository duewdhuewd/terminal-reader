# 终端阅读器（Terminal Reader）

在 VS Code 的终端面板里分页阅读本地 **txt / Markdown** 文档。适合在工作间隙看小说、长文档或日志，不需要额外窗口。

```
┌──────────────────────────────────────────┐
│ 第一章 开始                              │
│                                          │
│ 这是一段正文。终端宽度变化时，文字会重新 │
│ 排版，中英文混排也不会错位。             │
│                                          │
│ 12/86 页 · 13.9% · 第一章 开始   ? 帮助  │
└──────────────────────────────────────────┘
```

## 功能

- 在 **TERMINAL** 面板中使用伪终端全屏阅读，支持窗口缩放重排。
- 自动识别 txt 章节（`第X章`、`Chapter 1`、`序章`、`番外` 等），Markdown 使用 `#` 标题生成目录。
- Markdown 渲染：标题、列表、引用、代码块、表格、链接与内联样式会转换为适合终端阅读的纯文本。
- 目录跳转、全文搜索（高亮 + 上一个/下一个）、指定页跳转。
- 支持鼠标滚轮滚动（正文、目录、帮助页）。
- 自动记住每个文件的阅读位置，支持“最近阅读”。
- 自动识别 UTF-8 / UTF-8 BOM / UTF-16 / GB18030（GBK）编码。
- 中文宽字符、Emoji 按终端显示宽度排版，避免折行错位。

## 安装

### 从源码运行（开发）

```bash
cd terminal-reader
npm test
```

用 VS Code 打开该目录，按 `F5` 启动扩展开发宿主，然后打开任意 `.txt` / `.md` 文件执行命令。

### 安装打包好的扩展

```bash
npx @vscode/vsce package
code --install-extension terminal-reader-0.1.1.vsix
```

## 使用

有三种入口：

1. 打开 `.txt` / `.md` 文件后，点击编辑器标题栏的 **书本图标**。
2. 在资源管理器中右键文件，选择 **在终端中阅读**。
3. 命令面板（`Ctrl+Shift+P`）：
   - `终端阅读器: 在终端中阅读当前文件`
   - `终端阅读器: 打开文件并阅读…`
   - `终端阅读器: 打开最近阅读`
   - `终端阅读器: 清除全部阅读进度`

阅读位置会在翻页后自动保存，关闭终端或重新打开文件时恢复。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| `空格` / `PageDown` / `f` | 下一页 |
| `b` / `PageUp` | 上一页 |
| `↓` / `j` | 向下滚动一行 |
| `↑` / `k` | 向上滚动一行 |
| `Home` / `End` | 跳到开头 / 结尾 |
| `g` | 跳转到指定页 |
| `[` / `]` | 上一章 / 下一章 |
| `t` | 打开目录 |
| `/` | 搜索 |
| `n` / `N` | 下一个 / 上一个搜索结果 |
| `Esc` | 清除搜索或关闭弹层 |
| `r` | 重新加载文件 |
| `?` | 显示 / 关闭帮助 |
| 鼠标滚轮 | 向上 / 向下滚动 3 行 |
| `q` / `Ctrl+C` | 退出阅读器 |

启用鼠标滚轮后，终端会捕获鼠标事件。此时如果想选中并复制文字，请**按住 `Alt` 拖动**（macOS 为 `Option`）。也可以在设置中关闭 `terminalReader.mouseWheel`，恢复普通终端的选择行为。

目录中可用 `↑` / `↓` / `PageUp` / `PageDown` 选择，`Enter` 跳转，`Esc` 返回。帮助页较长时可用 `j` / `k` 滚动。

## 设置

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| `terminalReader.maxFileSizeMB` | `10` | 允许打开的最大文件大小（MB） |
| `terminalReader.preservePosition` | `true` | 是否记住每个文件的阅读位置 |
| `terminalReader.mouseWheel` | `true` | 是否启用鼠标滚轮滚动 |
| `terminalReader.chapterPattern` | 见下 | txt 章节标题正则 |

默认章节正则：

```regex
^\s*(?:第\s*[0-9零一二三四五六七八九十百千万两〇]+\s*[章节回卷篇部集]|(?:Chapter|CHAPTER)\s+[0-9IVXLCDM]+|序章|楔子|前言|后记|尾声|终章|番外)
```

如果小说章节是 `【第1章】`、`卷一` 等格式，可以在设置中改成自己的正则，例如：

```json
{
  "terminalReader.chapterPattern": "^\\s*(?:【第\\d+章】|卷[一二三四五六七八九十]+)"
}
```

## 说明与限制

- 只支持本地 `file://` 文件；暂不支持 EPUB / PDF / 远程虚拟文件系统。
- 搜索按“屏幕行”匹配，跨换行的短语不会被命中。
- 阅读位置保存在 VS Code 全局状态中，最多保留 200 个文件。
- 文本中的 ANSI 控制序列会被清理，避免污染终端。

## 开发

项目使用纯 JavaScript，无运行时依赖：

```
terminal-reader/
├─ extension.js        # 扩展入口、命令、状态持久化
├─ src/
│  ├─ document.js      # 编码识别、Markdown/txt 解析、折行模型
│  ├─ reader.js        # 伪终端阅读器、键盘交互、渲染
│  ├─ ansi.js          # 显示宽度、ANSI 样式、截断与高亮
│  └─ keys.js          # 终端按键序列解析
├─ test/               # node:test 单元测试（含 vscode stub）
└─ samples/            # 示例文档
```

```bash
npm test        # 运行全部测试
npm run check   # 语法检查
```
