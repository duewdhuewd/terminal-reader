# 终端阅读器示例

这是一份用于演示 **Markdown 渲染** 的文档。你可以在终端里用 `空格` 翻页，按 `t` 打开目录，按 `/` 搜索内容。

## 支持的语法

### 列表与强调

- **加粗文字** 会保留内容，去掉标记
- *斜体文字* 同样只保留内容
- `行内代码` 会去掉反引号
- [链接文字](https://example.com) 只显示文字
- ~~删除线~~ 也会被清理

### 引用

> 阅读不是逃离生活，而是带着更多的问题回到生活里。
>
> 一本书读到最后，留下来的往往不是情节，而是某种看世界的方式。

### 代码块

```js
function greet(name) {
  console.log(`你好，${name}`);
}
```

### 表格

| 按键 | 功能 |
| --- | --- |
| 空格 | 下一页 |
| t | 目录 |
| / | 搜索 |

## 长段落

终端阅读器的排版会按照终端当前的列数自动折行。中文字符占两个显示宽度，英文字符占一个显示宽度，因此中英文混排时不会出现半个字被截断的情况。当你拖动 VS Code 面板、调整终端高度，或者切换全屏时，阅读器会重新计算折行，并尽量保持当前段落的位置。

如果文件很长，可以使用目录直接跳到某一章。按 `]` 跳到下一章，按 `[` 返回上一章。搜索时会高亮所有命中位置，按 `n` 和 `N` 在结果之间移动。

## 结尾

按 `?` 随时查看快捷键，按 `q` 退出阅读器。
